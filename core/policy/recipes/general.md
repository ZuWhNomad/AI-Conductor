This is a default method, not a rule set.

Restate the goal in the task's own terms.
Say what done means, in those same terms.
If either is unclear, ask once, then proceed on the answer.
Look for an existing route before inventing one.
The capability index, an existing program, or a neighbouring framework may already cover it.
Use what you found when it covers the work.
Take the smallest step you can verify first.
Say how that step will be checked before you take it.
Check it.
Report what was not verified.
Log what worked.
If this kind of work will recur, say so.
